# Agastya Martial Arts & Fitness Academy

A premium academy management dashboard built for a luxury fitness and martial arts business.

## Features
- Client database management
- Attendance register
- Notification and announcement center
- Fee ledger and digital payment gateway UI
- Receipt generation preview
- Premium red-and-gold branding for Agastya Martial Arts & Fitness Academy

## Run locally
Open `index.html` in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure
- `index.html` — app shell
- `styles.css` — premium theme and responsive styling
- `app.js` — client data, attendance logic, payment flows, notification center
